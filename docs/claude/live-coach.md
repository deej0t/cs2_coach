# Live-Coach (GSI)
← [[CLAUDE]] · Detailnotiz, wird nur bei Bedarf gelesen.

## Live Coach in real matches (`live_coach.py`, `web/live_page.py`)
- **Game State Integration** (Valve's official interface, own data only - no enemy positions): the user drops `gamestate_integration_cs2coach.cfg` (download on `/live`) into `game/csgo/cfg/`; the client POSTs to `/api/gsi/<token>` (public like the server-log ingest, token in URL **and** `auth.token`, `.gsi_token` next to the config). The URL points at the LAN (`live_gsi_url`, else `server_rcon_host:5001`), never through Cloudflare.
- **Counts the early grenade in a full buy** (since 2026-11-13, same definition as the briefing goal): full buy = GSI `player.state.equip_value` >= 3700 at the first live payload (= `parser._FORCE_THRESHOLD`, rounds 1 and 13 never), early = a grenade leaves the inventory within 35 s of the round going live (clock = `provider.timestamp`), rounds you die in before 35 s do not count. Target = median early rate (%) in the player's **won** matches (same map if >= 5). Hints: at freeze time the quote (`5/7 Full Buys, Ziel 82 %`), after 20 s in a full buy without a grenade `Noch 15 s fuer die fruehe Granate: HE, Flash` (replaces the old 35-s-left reminder - taking grenades to the grave is no lever). Before, it counted grenades per round against the median of wins: 17 matches without measurable effect (d = 0.10). Not yet run in a real match - `equip_value` at the live tick is assumed, not measured.
- `ingest()` touches `.gsi_last` next to the config on every POST (the state file does not change in the menu); the start page shows "CS2 verbunden" when it is younger than 30 s, plus the last live-counted match (`live_matches/`, `summary.early/full_buys`) - that is where the first real match shows whether `equip_value` works.
- **Loud only when it counts** (2026-11-15, feedback "nicht wirklich bemerkt, obwohl vorgelesen"): on 2026-11-14 every round start read the same long sentence while he was on track (live 23/24, 10/10), so the one useful warning drowned. Each hint now carries `say` (spoken text) or none (display only): round start is silent unless below target (>= 3 full buys counted), the 20-s warning is `say="Granate!"` with a two-tone beep and a full-screen yellow/orange blinking overlay on `/live` (the user keeps it on his second monitor), halftime/game over/AI speak a short line. **Live counts throws up to `EARLY_THROW_SECONDS` = 33**: the demo counts detonations up to 35 s, and live (throw <= 35) read 23/24 and 10/10 where the demo said 16/20 and 8/10. A death seen only through the spectator switch now sets `died_s` too (before, an early death counted as a full buy without grenade). The AI hint said "dein Ziel sind aber 82 Prozent. Spare sie dir" at 100 % - facts now say "im Plan" / "unter dem Ziel" and the prompt forbids advising to save grenades.
- **Which grenade** (2026-11-15, `live_plan.py`): the 20-s warning names your most-thrown lineup for this map + side (`player.team`) among the grenades you carry, e.g. `GRANATE! Molly → Connector (12× von dir)`, spoken "Granate! Molly Connector". The plan is built in a thread (`ensure()`, O_EXCL `.live_plan.lock`, at most `MAX_NEW` = 3 new demo scans - Anubis took 31 s, Mirage 2.3 s) and never inside the GSI request (5 s timeout). Most *frequent*, not proven best - no lineup is measured as a lever. `/live` shows it as a match-plan card (top 3 per side, target, quote on the map, last result) and a round strip per full buy (`round_strip()`: ok / miss / open / dead).
- Counting: a grenade that leaves the inventory during a live round while alive = thrown; grenades held at death = "mit ins Grab". **While dead GSI shows the spectated teammate** - a foreign `player.steamid` during a live round means you died. `map.round` counts finished rounds (+1 = current).
- Hints: at freeze time (pace vs target, grenades wasted last round), once per round at <= 35 s left with grenades unused, halftime and game-over summary. At halftime and game over a background thread adds a Gemini hint (`ai_hint()`, kind `ai`, max 2 sentences, only the counted facts) - never inside a round, the AI takes seconds to minutes. Finished matches -> `live_matches/` (basis for "with vs without live coach" via `evidence.py` later). Not yet run in a real match.
